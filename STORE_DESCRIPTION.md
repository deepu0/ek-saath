# Store Detailed (for Chrome Web Store) — What it does + Why install

**Stop hunting tabs.**

You keep 30, 50, 100 tabs open. You open the same docs page again because you can't find the first one — scattered somewhere in the bar. Sound familiar?

**EkSaath fixes that.**

One click groups all tabs by domain: `1,2,3,4,1,3,4,2` → `1·1·1 — 2·2 — 3·3 — 4`. Same site, together. Now you instantly see you already have 4 tabs for that site — no need to open a fifth.

**What it does:**
- **Groups by domain** — alphabetical, stable order. `mail.google.com` and `docs.google.com` become one `google.com` block.
- **Shows duplicates** — live count: `2 groups · 5 extra tabs` right in the popup.
- **Closes duplicates** — `CLOSE 5` keeps the oldest, closes the rest. Undo for 30s.
- **Prevents future dups** — optional exact-URL dedupe when you open a tab (never touches pinned, chrome://newtab, localhost, or your whitelist).

**Why install:**
- Find tabs instantly — no more scanning 50 favicons.
- Stop accidental re-opens — see the count before you click.
- Clean clutter without fear — undo always available, pinned tabs never touched.
- Minimal, fast, private — reorder only, no tab groups clutter. Only `tabs` + `storage` permissions, no data leaves your device.

For anyone who hoards tabs with affection. One click, sab ek saath.

Shortcut: `Alt+Shift+R` · Basic always visible, advanced when you need it.
