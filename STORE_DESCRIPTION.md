# Store Detailed (for Chrome Web Store)

I keep 50+ tabs open. I don't close them — I might need them later.

Problem: I open the same URL again and again without realizing. 5 copies of the same docs page, scattered across the bar. Clutter, but I don't want to lose anything.

**Domain Grouper fixes that.**

One click → `1,2,3,4,1,3,4,2` becomes `1·1·1 — 2·2 — 3·3 — 4`. Same domain, together. Now you see: "Oh, I already have 4 tabs for this site — no need to open another."

- **Reorder only** — no tab groups clutter. Alphabetical, stable. `mail.google.com` = `google.com`
- **See duplicates** — live count: `2 groups · 5 extra`
- **Close duplicates** — one tap `CLOSE 5`, keep oldest, undo 30s
- **Prevent future dups** — exact URL dedupe on open (optional, with whitelist)
- **Respects your tabs** — never touches pinned, `chrome://newtab`, `localhost`

For anyone who hoards tabs with affection. You might not need it, but if you do — you'll feel it.

Minimal UI. Basic always, advanced when you need it. Shortcut `Alt+Shift+R`.
